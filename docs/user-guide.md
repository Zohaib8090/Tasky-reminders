# User guide

## Tasks
1. Open the **Today** tab and tap the add button.
2. Enter a title and optionally a description, due date and time, **priority** and **category**.
3. Add checklist steps, attachments, or a quick note.
4. Choose a **reminder**: at the due time, or 5, 10, 15, 30 or 60 minutes or 1 day before.
5. Save. The reminder fires as a notification with **Mark done** and **Snooze** actions.

Tap a task to see its details. Tick the circle to complete it. Use **Calendar** to browse by day.

Allow notifications when asked. On some phones, also allow exact alarms and exclude TaskNest from battery optimisation so reminders arrive on time. Use "send test reminder" in the task sheet to check.

## Notes
- Open the **Notes** tab and tap the add button, then give the note a title.
- Write in the body. Bold and Italic apply to the note text.
- Tap **"+"** in the toolbar for the full list: checklist, image, video, link, audio, file.
- The checklist only appears once you add the first item.
- A note can be linked to a task, shown as a chip under the title.
- Changes save automatically. Deleting a note asks you to confirm first.

## Locking
- **Note:** tap the lock icon in the editor's top bar.
- **Task:** turn on **Lock this task** when adding or editing it.
- Your phone must have a screen lock or fingerprint/face set up.
- Locked items show only "Locked" in lists. Opening, editing or deleting one asks for fingerprint, face or your device PIN/pattern/password.
- They lock again each time you leave the app. The rest of the app is not locked.

## Appearance
In **Settings**, choose a colour palette and light, dark or system mode. The whole app, including the note editor, follows it.

## Backup and restore
**Settings, Local Backup & Restore.**
- **Backup** saves tasks, notes, checklists, settings and media to a zip file you choose.
- If you have locked items, you authenticate once and choose an **export password**. Locked items and their media are encrypted in the file with it. Write the password down: without it they can't be restored.
- **Restore** reads a zip. Choose whether to replace existing data or merge. If the file has locked items it asks for the export password; a wrong password changes nothing.
- Restored locked items stay locked and are re-encrypted for the new phone.

Backups are the way to move to a new phone.

## Updates
**Settings, App Updates.** "Check for updates" shows whether a newer version exists on GitHub, with its notes and a link to download. An optional once-a-day check is off by default. You install updates yourself from the downloaded APK.
